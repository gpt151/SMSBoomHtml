Minecraft启动器Fabric安装教程
PCL2 & HMCL 详细指南

本教程适用于 Minecraft Java 版 1.14 及以上版本，涵盖 PCL2 和 HMCL 两大主流第三方启动器的 Fabric 安装方法。

PCL2 启动器安装 Fabric 教程

1. 下载并安装 PCL2 启动器

下载 PCL2 MCBBS 下载
  1. PCL2 是国产优秀启动器，无需安装 Java 即可运行
  2. 下载后解压到任意文件夹（建议不要放在系统盘）
  3. 双击 PCL2.exe 运行启动器

PCL2 启动器主界面

2. 下载 Minecraft 游戏版本

  1. 在 PCL2 主界面点击"下载游戏"
  2. 选择你想安装的 Minecraft 版本（建议 1.16.5 或更高）
  3. 点击右侧的"安装"按钮
  4. 等待下载和安装完成

3. 安装 Fabric Loader

  1. 返回主界面，点击"版本设置"
  2. 选择你刚安装的游戏版本
  3. 点击"安装 Fabric"按钮
  4. 在弹出的窗口中选择 Fabric 版本（建议选择最新稳定版）
  5. 点击"确定"开始安装
  6. 安装完成后会生成一个带 Fabric 后缀的新版本

提示： PCL2 会自动处理 Fabric API 的安装，无需手动下载。

4. 安装模组

  1. 在 PCL2 主界面点击"下载模组"
  2. 搜索你想要的模组（确保选择 Fabric 版本）
  3. 点击"下载"按钮
  4. 或者手动下载模组文件(.jar)后，放入： 游戏目录/mods 文件夹
  5. 启动游戏时选择带有 Fabric 的版本

注意： 确保所有模组都兼容你安装的 Minecraft 和 Fabric 版本。

HMCL 启动器安装 Fabric 教程

1. 下载并安装 HMCL 启动器

官方下载 MCBBS 下载
  1. HMCL 是开源免费的启动器，需要 Java 环境
  2. 下载后得到 .jar 文件，双击运行（需已安装 Java）
  3. 首次运行会要求设置游戏目录（建议新建文件夹）

2. 下载 Minecraft 游戏版本

  1. 点击主界面"游戏列表"下方的"安装新游戏版本"
  2. 选择你想安装的 Minecraft 版本
  3. 点击"安装"按钮
  4. 等待下载完成

3. 安装 Fabric Loader

  1. 返回主界面，点击"安装新游戏版本"
  2. 切换到"安装 Fabric"标签页
  3. 选择 Minecraft 版本和 Fabric 版本
  4. 点击"安装"按钮
  5. 安装完成后会生成一个新的 Fabric 版本

提示： HMCL 也可以安装 Forge 和 Quilt，方法类似。

4. 安装 Fabric API 和模组

  1. 在 HMCL 主界面点击"模组管理"
  2. 点击"下载模组"可以自动搜索和下载 Fabric API 及其他模组
  3. 或者手动下载模组文件(.jar)后，拖入模组管理界面
  4. 确保 Fabric API 是最新版本且与其他模组兼容
  5. 启动游戏时选择 Fabric 版本

注意： HMCL 可以自动解决部分模组依赖关系，但冲突的模组仍需手动处理。

常见问题解答

Q1: 安装 Fabric 后游戏崩溃怎么办？

  1. 检查崩溃日志（在 crash-reports 文件夹）
  2. 尝试移除最近添加的模组
  3. 确保 Fabric Loader 和 API 是最新版本
  4. 在 PCL2/HMCL 中尝试修复游戏

Q2: 如何更新 Fabric 版本？

PCL2: 在"版本设置"中重新安装 Fabric

HMCL: 在"安装新游戏版本"中选择新版 Fabric

Q3: 模组不显示或不起作用？

  1. 确认模组文件在正确的 mods 文件夹
  2. 检查模组是否与当前 Minecraft 和 Fabric 版本兼容
  3. 确保你选择了正确的 Fabric 版本启动游戏
  4. 有些模组需要额外的库文件（如 Fabric API）
